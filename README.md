# Work map

A local window onto a software build tracked in GitHub. Each section of the project is a card, and each card shows how much of its scope is live, merged, built or still planned, with its open pull requests, blockers and review state. It is for people who build with AI coding agents and want to see where the work stands at a glance.

Work map is being rewritten in Rust as a small app for macOS, Windows and Linux. It can also run without a window and serve the map at a local web address. It works alone, and if [Seat Gauge](https://github.com/LaunchAstro/seat-gauge) is installed it also shows which agents are working on each section.

**Status: planning.** The plan lives in this repository's issues, starting from the map issue labelled `wayfinder:map`. There is nothing to install yet.
